# 参数字段

锁定用户明确填写的字段，只对缺失字段执行合理补全。字段补全不得替换用户方向。下表的创作默认值适用于无原图的文本创作；照片保真任务优先继承原图，不得用年龄、五官、服装、姿态、镜头或画幅的默认值覆盖原图锁定项。新增参考图字段均非必填，旧参数继续有效。

| 字段 | 说明 | 默认值 |
| --- | --- | --- |
| 写真风格 | 选择唯一主路由 | 根据用户意图判断；无法判断时使用清纯生活照 |
| 场景方向 | 指定拍摄环境 | 与主路由协调的简洁场景 |
| 服装方向 | 描述颜色、版型、材质和搭配 | 与主路由匹配的完整服装 |
| 配色方向 | 控制主色、辅色、金属或珠宝点缀色及其占比 | 与主路由协调；用户指定时锁定 |
| 华丽度 | 控制刺绣、材质、发饰、首饰、服装层次和背景复杂度 | 与主路由协调；不适用时不特别强调 |
| 年龄特征 | 控制可见年龄段与成年表现 | 24–28 岁年轻成年东方女性，成年气质明确 |
| 气质标签 | 描述人物整体气质 | 自然、干净、明确成年 |
| 五官方向 | 控制脸型、眉眼、神情和妆容 | 与主路由协调的东方女性五官 |
| 身形方向 | 控制比例、姿态和镜头配合 | 自然协调身形 |
| 身形吸引力强度 | 控制线条表达程度 | 弱或中 |
| 线条重点 | 指定需要通过姿态、服装和光线呈现的区域 | 与服装和镜头匹配 |
| 镜头方向 | 控制景别、姿态和重点 | 半身到大腿或大腿以上 |
| 光线氛围 | 控制光源效果 | 柔和自然光 |
| 滤镜效果 | 控制色彩和摄影质感 | 与主路由匹配 |
| 画幅比例 | 控制成图比例 | `9:16` |
| 尺寸参数 | 控制像素尺寸、分辨率或宽高；仅在用户明确填写时锁定，不得虚构 | 未指定 |
| 平台用途 | 控制构图和信息密度 | 生活照 |
| 输出模式 | 控制返回内容 | 标准：参数锁定 + 逐段导演式模块扩写 + 五段式最终提示词 + 负面约束；最终提示词与负面约束分别使用 Markdown `text` 代码块 |
| 补充要求 | 用户额外限制 | 保持真实、完整、风格统一 |
| 图片角色 | 标记每张上传图片的用途 | 未上传图片时为空；上传后必须明确标记 |
| 保留对象 | 指定必须保持不变的人物或产品特征 | 照片转换默认锁身份、面部特征、发型、服装、动作、主体数量、机位、构图和裁切；产品锁核心视觉 |
| 锁定强度 | 保留旧字段，用于说明参考图保护范围 | 按任务模式锁定；不得因省略此字段缩小照片保护范围 |
| 参考图模式 | 可选：`source_faithful_stylization` / `identity_restage` / `protected_region_edit` | 照片风格转换为 `source_faithful_stylization`；严格原图不变为 `protected_region_edit`；明确换装/重排任务为 `identity_restage` |
| 允许改变 | 可选，仅解除明确列出的项目；接受“允许修改”别名 | 仅用户请求的变化，不自动开放其他项目 |
| 禁止改变 | 可选，明确加强保护 | 继承模式保护范围 |
| 保护区域 | 可选，使用像素坐标或明确的保护遮罩指定区域 | 严格原图不变时为全部原图区域；仅编辑区可变 |
| 原图尺寸 | 可选，记录源图宽高像素 | 从图像读取；无法读取时标为未知，不虚构 |

## 参考图字段

参考图提示词和实际编辑均按 [core/reference-image-lock.md](core/reference-image-lock.md) 建立锁定表。是否调用图像工具由输出要求决定，上传图片本身不构成出图请求；“只要提示词”始终保持文本输出。以下字段均可用自然语言表达，不要求用户重填完整模板：

```text
图片角色：
- 图片 1：identity_reference / product_reference / style_reference / edit_target
- 图片 2：identity_reference / product_reference / style_reference / edit_target

参考图模式：source_faithful_stylization / identity_restage / protected_region_edit

保留对象：
- 照片风格转换：身份、五官、发型、服装、动作与姿态、主体数量、机位角度、构图、裁切
- 产品：品类、轮廓、颜色、材质、图案、关键结构

锁定强度：沿用旧字段；不能自动解除上述保护
允许改变：（接受“允许修改”）
禁止改变：
保护区域：像素坐标或二值 L 模式蒙版；黑色 0 为保护区，白色 255 为允许编辑区
原图尺寸：宽 × 高像素
```

图片角色可根据用户明确指示确定；用途或多图角色仍有歧义时先询问，不自行猜测。`identity_restage` 只允许改变用户明确列出的项目。`protected_region_edit` 要求确定性保护受保护原像素并进行像素验证，不能以提示词约束代替。保护区域默认采用原图像素坐标；扩图另行记录原图在输出画布中的位置。原图尺寸和目标尺寸分开记录，冲突时先澄清，禁止静默缩放或裁切。
