# 公开调用说明

这个 Skill 以 Markdown 指令把少量女性人像参数扩写成完整、可直接复制的提示词，不内置图片生成或编辑工具。宿主具备相应图像能力、且用户明确要求出图时，才编排授权参考图生成或编辑。文本创作可补全画面；照片保真转换则先锁定原图特征，仅在允许改变的范围内应用风格。

## 首次调用

安装后只发送以下内容即可打开 V1.6 新手教学：

```text
$female-portrait-director
```

系统会显示 20 种已实现风格、基础与高级参数模板、一个从参数组合到五段式详细提示词的完整示例，以及直接出图和参考图用法。完整教学见 [help.md](help.md)。

## 输出模式

- `简洁`：只返回最终提示词和负面约束。
- `标准`：默认模式。返回参数锁定、逐段导演式模块扩写、五段式最终提示词和负面约束。模块扩写至少包含年龄与五官、身形与仪态、服装配色与发饰、华丽度的可见设计、场景、镜头、光线与滤镜。最终提示词和负面约束分别使用独立 Markdown `text` 代码块，便于直接复制。
- `导演详版`：在标准模式基础上，进一步说明瞬间、动作链、选择性环境细节、参数扩写关系、镜头目的与光线设计。
- `直接生成图片`：用户明确要求出图后，调用宿主实际可用的图片生成能力。
- `参考图直接生成`：在用户明确要求出图、宿主支持输入参考图或编辑原图时，锁定主体后调用相应能力，默认不输出内部提示词。宿主无合适工具时说明限制，按用户要求提供提示词或编辑方案，不声称已生成图片。

直接说 `只要最终提示词` 或 `只要提示词` 等同于选择提示词输出。即使上传参考图，也不得因此改成生图；仅上传图片或填写参数不构成出图请求。

最终提示词第一句必须写明画幅比例。用户额外填写像素尺寸、分辨率或宽高时，系统必须保留原值并一并写入第一句；用户未填写时不得虚构具体像素值。

## 参考图保真与可选模式

照片风格转换默认锁定身份和面部特征、发型、服装、动作与姿态、主体数量、机位与拍摄角度、构图和原始裁切；只改变用户指定的风格表现。五官方向、服装模板、Route 或 Overlay 都不得覆盖这些锁定项。

以下字段均非必填，原有参数和自然语言请求继续有效：

```text
参考图模式：source_faithful_stylization / identity_restage / protected_region_edit
允许改变：仅列出希望修改的项目（也接受“允许修改”）
禁止改变：
保护区域：原图中不得改变的区域；可给出坐标或明确的遮罩
原图尺寸：宽 × 高，单位为像素；未知时读取原图，不虚构
```

`source_faithful_stylization` 用于保持原照片结构的风格转换；`identity_restage` 用于明确要求换装、重排姿态或更换场景的任务，仍只改变显式允许项目；`protected_region_edit` 用于“原图不变”或局部编辑/扩图，须确定性保留受保护原像素并验证。保护区域与允许修改重叠时，先解决冲突。

严格原区域不变需要保存原像素、遮罩限定可编辑区域、生成后回贴受保护原像素，并验证保护区域像素相等。只靠提示词或图像模型的“保留原图”承诺不足以证明通过；宿主工具不支持时先说明限制。详见 [core/reference-image-lock.md](core/reference-image-lock.md) 和 [验证方法](../docs/reference-fidelity-validation.md)。

## 参考图直接生成

```text
保留我的五官，生成复古港风写真
用我的自拍做一张古风仙侠图
保持这个产品不变，生成一张高级广告图
保留我的脸，穿上第二张图里的衣服
```

上述换装或重新布景示例属于 `identity_restage`，仅解除用户明确允许改变的项目。人物参考图仅支持本人或已授权的成年人物。产品默认锁定品类、轮廓、颜色、材质、图案和关键结构。Logo 与小字尽量保留，但不承诺逐字准确。

## 使用边界

文本生图默认人物必须是虚构、明确成年的女性。参考图编辑允许本人或已授权成年人物。完整边界见 [../docs/prompt_safety.md](../docs/prompt_safety.md)。
